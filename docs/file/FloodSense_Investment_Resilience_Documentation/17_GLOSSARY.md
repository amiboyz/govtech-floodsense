# Glossary

**Forecast:** future prediction for a horizon. **NowCast:** current/near-current situation. **PostCast:** post-event reconstruction. **TMA:** tinggi muka air. **Pluvial:** local rainfall/drainage-driven flooding. **Fluvial:** river overflow-driven flooding. **Lead time:** time between alert and event. **Freshness:** data age relative to SLA. **Provenance:** source and transformations. **Exposure:** assets/people/investments in hazard area. **Vulnerability:** susceptibility to damage. **Resilience:** anticipate, absorb, recover, adapt. **Basis risk:** mismatch between index and actual loss. **CRS:** coordinate reference system. **RBAC:** role-based access control. **Data leakage:** using unavailable future information. **Calibration:** probability-frequency agreement. **False alarm:** alert without defined event. **Missed event:** event not detected. **Due diligence:** evidence review, not a guarantee.
