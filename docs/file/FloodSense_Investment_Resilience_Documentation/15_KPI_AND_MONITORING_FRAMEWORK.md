# KPI and Monitoring Framework

## Adoption/product
Locations/portfolios assessed; active JIC users; workflow completion; median time to draft; percentage of reports without major data correction.

## Data
Source coverage; ingestion success; stale rate; completeness; quarantine rate; issue resolution time; verified-coordinate coverage.

## Model/alert
Precision, recall/POD, false alarm, missed event, lead time, calibration/Brier, coverage, acknowledgement, action completion, drift/fallback.

## Reliability/security
Availability/latency/error; job delay; backup and restore success; incidents; unauthorized attempts.

## Outcome
Due diligence that includes flood risk/mitigation; reduced time to identify exposed portfolio; mitigation follow-up rate. Baseline must be established.

## Guardrails
100% operational forecast has provenance/model version; missing evidence is explicitly `insufficient_data`; zero restricted-data publication; no automated investment decision from score.
