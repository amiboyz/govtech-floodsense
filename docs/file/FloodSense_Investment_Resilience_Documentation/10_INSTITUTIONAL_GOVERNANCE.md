# Institutional Governance

## Prinsip
Lokasi/nama aset tidak otomatis membuktikan kewenangan. Simpan reported owner, administrative owner, technical manager, source document, valid period, dan verification status.

## Forum
Product Steering; Data Governance; Model Review; Security/Privacy Review.

## Artefak wajib
Data-sharing agreement, data dictionary, source registry, decision log, model card, validation report, privacy/security assessment, SOP alert, SOP publikasi, backup/DR runbook.

## Konflik sumber
Simpan kedua klaim; tampilkan konflik; assign steward/owner; periksa dokumen primer; catat resolusi dan masa berlaku. Jangan overwrite diam-diam.
