# Implementation Roadmap

## Phase 0 — Discovery & governance
Audit repo/database/data/rentang waktu/lisensi; konfirmasi persona/UAT/RACI/scope. Output: source registry, data dictionary, gap report, backlog.

## Phase 1 — Data foundation & NowCast
Raw/staging/curated; master locations; map investment/TMA/rain/events/freshness; RBAC/provenance/audit. Exit: integration/UAT.

## Phase 2 — Exposure & Due Diligence
Hydrologic relations; exposure engine; portfolio view; report; review/publish workflow. Exit: traceable report tanpa kebocoran restricted.

## Phase 3 — Forecast terukur
Baseline; feature pipeline; rolling backtest; model registry; calibration; lead-time evaluation. Exit: model review dan fallback.

## Phase 4 — Alerts & continuity
Trigger, dedup, acknowledgement, playbook, delivery. Exit: tabletop exercise dan delivery test.

## Phase 5 — Scale
Score versioned, scenarios, opportunity layer. Insurance readiness hanya bersama institusi berizin dan kajian khusus.

Setiap fase wajib memiliki owner, data dependency, acceptance criteria, security review, rollback, evidence test, dan keputusan go/no-go.
