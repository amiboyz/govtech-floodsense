# Security, Privacy, and Compliance

## Ancaman
Credential leakage, kebocoran identitas/foto, broken object authorization, manipulasi threshold/model, data poisoning, upload berbahaya, signed URL panjang umur, ekspor tanpa audit, prompt injection dari dokumen, dan misrepresentasi analitik.

## Kontrol
IAM dan least privilege; review akses; secret manager/environment; encryption transit/rest; row/object authorization; upload validation/antivirus; checksum evidence; audit model/config/export/publish; backup terenkripsi dan restore test; dependency/image scanning; konten eksternal diperlakukan sebagai data, bukan instruksi.

## Privasi
Inventory → classification → minimization → purpose limitation → approval → retention → deletion. Demo publik hanya data publik/agregat atau sintetis yang ditandai.

## Incident response
Detect, contain, preserve logs, notify owner, assess impact, recover, post-incident review. Kontak dan SLA ditetapkan sebelum produksi.

## Catatan kepatuhan
Bukan opini hukum. Dasar pengolahan/berbagi/retensi/keterbukaan/pengamanan harus ditinjau terhadap regulasi Indonesia dan kebijakan Pemprov DKI yang berlaku, termasuk mandat pemilik data dan pelindungan data pribadi.
