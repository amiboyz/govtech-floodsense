# User Roles and Workflows

## Roles
Public (agregat disetujui); Investor/Manager (portofolio sendiri); JIC Analyst; Hydrology Analyst; Field Officer; Data Steward; Executive; Publisher; Administrator. Admin teknis tidak otomatis memperoleh akses seluruh data restricted.

## Due diligence
Cari/daftarkan lokasi → validasi geometry/source → ambil event/hydrology/assets/access → hitung indikator+confidence → review evidence/conflict → draft → technical/JIC review → publish approved version.

## Business continuity alert
Feed lulus QC → rule/model trigger → exposure engine → deduplication → operator verification bila perlu → delivery → acknowledgement/action → post-event evaluation.

## Data quality issue
Detect → quarantine/flag → assign steward → investigate → correct mapping/transformation → reprocess versioned → close with evidence.

## Segregation
Pembuat report bukan satu-satunya approver; threshold/model material memerlukan approval; Data Owner, Custodian, Model Owner, dan Publisher dibedakan.
